# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability in terraform-infra-blueprints, please report it responsibly.

Do not open a public GitHub issue. Instead, email:
gerardrecinto@gmail.com

Please include:
- A description of the issue and potential cloud impact
- The module and configuration snippet to reproduce
- Suggested mitigation if available

Reports are acknowledged within 48 hours with an assessment and remediation plan.
